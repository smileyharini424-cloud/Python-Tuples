# Python Tuples

## Explanation

A tuple is an ordered collection of elements in Python. Unlike lists, tuples are immutable, which means their elements cannot be changed after creation.

Tuples are created using parentheses `()`.

## Problem Statement

Write a Python program that creates a tuple and demonstrates accessing elements, negative indexing, and slicing.

## Features

* Creates a tuple
* Displays tuple elements
* Accesses elements using indexing
* Uses negative indexing
* Demonstrates tuple slicing
* Displays the length of the tuple

## How It Works

The program creates a tuple containing student details and performs different operations on it.

Since tuples are immutable, the program only accesses and displays their elements without modifying them.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Create a tuple.
3. Display the complete tuple.
4. Access the first element.
5. Access the last element.
6. Perform tuple slicing.
7. Find the tuple length.
8. Display the results.
9. End the program.

## Sample Output

```text id="q5m8rz"
Tuple: ('Harini', 20, 'CSE', 'Hyderabad')
First Element: Harini
Last Element: Hyderabad
Sliced Tuple: ('Harini', 20, 'CSE')
Length: 4
```
